# Data Availability

Use this file as the source for the manuscript's `Data availability` section.

## Nature Portfolio expectations

Nature Portfolio requires a `Data availability` statement describing access to the minimum dataset needed to interpret, verify and extend the study. For large datasets, deposition in a public repository is preferred over supplementary files.

Source:

- https://www.nature.com/nature-portfolio/editorial-policies/reporting-standards

## Data classes in this project

- paired phase-contrast and SYTOX Green images used for annotation and evaluation
- YOLO-formatted training labels generated from fluorescence-anchored annotation
- validation and independent test datasets used in the manuscript
- trained model checkpoints

## Suggested manuscript text

```text
Data availability
The minimum image datasets and annotation files required to reproduce the analyses in this study are available at [insert repository name and persistent accession/DOI]. Trained model checkpoints corresponding to the manuscript release are available at [insert archive DOI or release URL]. Additional raw image data are available from the corresponding authors upon reasonable request if not already included in the public repository.
```

## Before submission

- deposit the minimally sufficient public dataset in an archival repository
- provide persistent identifiers for both data and model checkpoints
- make sure the accession identifiers in the manuscript and README match the final release
- state any data-sharing restrictions explicitly if they exist
