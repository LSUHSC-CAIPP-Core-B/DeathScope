# Training Workflows

This directory contains the interactive and script-based training materials for the two released DeathScope model components.

- [YOLO/README.md](YOLO/README.md)
  Detector training for apoptosis and necroptosis localization.
- [ConvNeXt/README.md](ConvNeXt/README.md)
  Crop preparation, ConvNeXt-Large training, plotting, and inference notebooks for the apoptosis-versus-pyroptosis refinement classifier.

Use the YOLO workflow for detector retraining and the ConvNeXt workflow for the optional second-stage classifier.
